# Reframe - AI-Powered Cognitive Reframing App

A beautiful iOS app that helps users reframe negative thoughts using AI-powered cognitive behavioral therapy techniques.

## 🌟 Features

### 🤖 AI-Powered Coaching
- **Personal AI Coach**: Get personalized guidance for emotional challenges
- **Cognitive Reframing**: Transform negative thoughts into positive perspectives
- **Emotional Framing**: Learn to view situations from different angles

### 📱 Core Features
- **Thought Reframing**: Input negative thoughts and get AI-generated reframes
- **Journaling**: Guided journaling with prompts and mood tracking
- **Streak Tracking**: Build consistent mental health habits
- **Achievements**: Gamified progress tracking with milestones
- **Calming Tools**: Breathing exercises and grounding techniques
- **Daily Wisdom**: Inspirational quotes and strategies

### 🎨 Beautiful Design
- **Modern UI**: Clean, intuitive interface with smooth animations
- **Dark/Light Mode**: Automatic theme switching based on system preferences
- **Accessibility**: Designed with accessibility in mind
- **Widget Support**: iOS widget for daily motivation

## 🛠 Technical Stack

- **Platform**: iOS 15.0+
- **Language**: Swift 5.0
- **Framework**: SwiftUI
- **Backend**: Firebase (Firestore, Authentication)
- **AI**: OpenAI GPT for cognitive reframing
- **Architecture**: MVVM with Combine
- **Dependencies**: Swift Package Manager

## 🚀 Getting Started

### Prerequisites
- iOS 15.0+ device or simulator
- Firebase account
- OpenAI API key
